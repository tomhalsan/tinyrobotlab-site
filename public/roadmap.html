Known boundaries

These are limits of the current implementation, not broader claims about what agent systems can do.

  • Evaluated evidence is not factual truth.

    The evaluator ranks retrieved material; it does not independently establish that a claim is true. How It Works explains this distinction.

  • Provider health is checked per task.

    The v0.4.0 release describes task-scoped health evaluation, not a continuously maintained provider-health service.

  • Tool coordination is bounded and not generally wired into agent services.

    The shared coordinator allows at most one invocation per coordination request. A fixed Tavily-over-MCP research executor is a separate integration, not a general agent tool loop.

  • Authorization is not sandboxing.

    Exact-tool grants and audit checks do not constrain the resources an authorized tool implementation can access.

  • Operational events are not durable analytics.

    The shared recent-event stream is bounded (about 500 entries). Tool telemetry is a best-effort terminal event and does not detect a hung or crashed invocation.

  • Local inference remains experimental.

    The repository documents local-model evaluation and hardware experiments, while lightweight and high-performance local-provider issues Tiny-Robot-Lab/autonomous-agent-lab#13 and Tiny-Robot-Lab/autonomous-agent-lab#14 remain open in the v0.9.0 milestone. Those experiments are not production provider adapters.

v0.5.0 - Tool-Using Agents

The GitHub milestone is open. Several tool-use foundations are implemented and tested on the current main branch, but that does not mean general tool use is integrated into the agent task runtime.

Current implementation state against the open milestone
Work area Verified state
Discovery and MCP

Implemented: shared tool contracts and registry, capability-scoped discovery, MCP clients for stdio and Streamable HTTP, and a selectable Tavily-over-MCP Research Agent executor.

Tests: test_tool_discovery.py, test_mcp_client.py, test_mcp_http_client.py, test_mcp_tavily_executor.py
Selection and coordination

Implemented and unit tested: deterministic tool selection, an explicit no-tool outcome, bounded argument correction, and coordination for at most one invocation.

Tests: test_tool_selection.py, test_tool_coordination.py
Agent-runtime integration

Still incomplete: no existing service calls the generic coordinator, so general agent-driven tool execution is not part of the task runtime. The fixed Tavily-over-MCP research executor is a separate integration.
Authorization and audit

Implemented in the shared coordination path: exact-tool, default-deny grants and required audit delivery before invocation. This is an authorization boundary, not a sandbox.

Test: test_tool_authorization.py
Telemetry and console

A terminal tool-execution event contract and Prototype Console rendering are implemented. The optional coordinator telemetry callback is not wired into the normal service task flows, so rendering support does not establish that those flows emit tool events.

Tests: test_tool_coordination.py, test_presentation.py
Open tracking

Tiny-Robot-Lab/autonomous-agent-lab#30 remains open for unavailable-tool and tool-failure tests. Current main already has focused unit cases for no match, a closed MCP client, invocation failures, and authorization denial; these do not establish end-to-end runtime integration.

Milestone status: open; no v0.5.0 release is listed.
