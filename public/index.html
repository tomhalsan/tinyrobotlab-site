Why I built this

For Tiny Agent Lab, I wanted to understand the work around a model call: how a task is routed, how agents communicate, and what the system does when a dependency fails. Reading about those ideas only goes so far, so I built a project where I could follow the code and observe the decisions.

Tiny Agent Lab is the result so far. I use this site to keep the diagrams, explanations, and mistakes close to the project—not to present it as a finished product.

Engineering note

A passing suite can still miss a cross-candidate bug.

In Tiny Agent Lab, a review of the research evidence scorer found that a stale loop variable could carry one candidate’s raw score into another. The fix and a regression test made that edge case explicit.
